# COMP1238 Notes

## Week 1 - History of Computing

- One writing system can be used by many languages.
- Early writing systems such as cuneiform were used to record information.
- The Epic of Gilgamesh is one of the earliest known works of literature.

## Week 2 - Bits and Bytes

- Computers store data using binary: 0s and 1s.
- A bit is the smallest unit of data.
- A byte is usually made up of 8 bits.
- Binary numbers can represent numbers, text, images, and other types of data.

## Week 3 - Number Systems

- Binary is base-2, decimal is base-10, and hexadecimal is base-16.
- Hexadecimal is often used as a shorter way to represent binary data.
- Converting between number systems is an important skill for understanding how computers store data.

## Week 4 - Text and Encoding

- Character encoding maps characters to numbers.
- ASCII is a common encoding standard for basic English characters.
- Unicode supports characters from many languages and symbol systems.
- UTF-8 is a widely used Unicode encoding.

## Week 5 - Files and Data

- Files store data in a structured way on a computer.
- File extensions help identify the type of file.
- Plain text files contain readable characters without complex formatting.
- Markdown is a simple markup language used to format text.
